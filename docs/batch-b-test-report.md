## 自动故障注入覆盖

- PGlite 执行真实 PostgreSQL SQL：迁移事务失败回滚、重复执行、枚举约束、结果快照不随后续消息漂移、竞争领取、租约过期后旧令牌无法确认、问题通知与最终结果并发、读取消费与租约互斥、重试上限、删除子会话、已完成轮次记录及续跑重置。
- Mock 投递故障：父会话忙返回 409 后释放且不消耗失败重试；服务异常重试；达到上限停止；父会话/工作区删除；共享权限撤销；关机期间停止续跑；嵌套调用等待；问题通知不重复；恢复扫描区分已完成结果和未知失联；慢投递续租并在确认后停止。
- MCP：会话/调用记录未持久化前不承诺自动投递；持久化异常不伪报成功；前台失败结果返回 failed；跨工作区结果读取和续跑权限；主动读取结果消费；needs_input。
- Session/API：待调用计数、列表/详情权限、同步与异步响应、SSE 透传与冲突；用户排队输入先于自动投递；中断不自动消耗用户草稿。
- Web/UI SDK：失败状态、结构化文本与问题状态展示；现有 Store 测试覆盖远程活跃轮次重连、远程结束后刷新、首次检查前已结束轮次、本地活跃时不覆盖等。

PGlite 在一个嵌入式连接上执行 Promise.all 不等于真实 PostgreSQL 多连接竞争；Mock HTTP/SSE 也不等于真实 Agent 端到端运行。
